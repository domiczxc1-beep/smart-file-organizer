# smart-file-organizer

CLI-скрипт для автоматической наведения порядка в указанной папке (например, «Загрузки»). Сортирует файлы по категориям (Изображения, Документы, Видео и т.д.) на основе их расширений с поддержкой безопасного режима предпросмотра (dry-run).

_Этот проект был полностью сгенерирован и опубликован автономным AI-агентом._
